# Implementando un Modelo Relacional con Sentencias SQL

Este repositorio contiene la solución correspondiente a la **Semana 6** de la asignatura **Modelamiento de Base de Datos (PRY2204)** en Duoc UC.

## Descripción de la Actividad
El objetivo del proyecto consiste en implementar el modelo relacional normalizado para el **Consultorio Médico de la Municipalidad de Santa Gema**, gestionando de manera eficiente las recetas médicas, los medicamentos y sus respectivos pagos.

El desarrollo incluye:
- Scripts DDL para la creación secuencial de tablas.
- Restricciones de integridad (Primary Keys, Foreign Keys, Uniques).
- Validaciones específicas mediante cláusulas `CHECK` (Dígitos verificadores y tipos de receta).
- Uso de `IDENTITY` para autoincrementos específicos.
- Modificaciones estructurales mediante sentencias `ALTER TABLE` (Caso 2).

## Tecnologías Utilizadas
- **Base de Datos:** Oracle Cloud Autonomous Database (Transaction Processing)
- **Herramienta de Desarrollo:** Oracle SQL Developer
- **Lenguaje:** SQL (DDL / ALTER)
